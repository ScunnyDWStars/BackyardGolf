# Course data

| File | What | Sources and licences |
| --- | --- | --- |
| `romanby.json` | Romanby Golf Club, all 18 holes | Layout © OpenStreetMap contributors, available under the [Open Database Licence (ODbL)](https://opendatacommons.org/licenses/odbl/); elevation from AWS Terrain Tiles (Mapzen Terrarium); hole 2 ground and splat alignment from a drone flyover reconstruction |
| `romanby-h2.json` | Hole 2 as captured from the flyover (hole frame), input to `scripts/attach-splat.ts` | Heightfield and layout measured from the reconstruction |
| `sample-course.json` | Synthetic three-hole course for development (not a real place) | Generated by `tests/sampleOsm.ts` |

`romanby.json` is a derivative of OpenStreetMap data and is shared under the ODbL. The game
shows the attribution on screen. Rebuild it with:

```bash
npx tsx scripts/bake-course.ts romanby-osm.json romanby-base.json
npx tsx scripts/attach-splat.ts romanby-base.json public/courses/romanby-h2.json 2 public/courses/romanby.json
```

The trained splat itself is not in this repository.
